Reinforcement learning in a browser tab

A language model wrote each of these worlds as plain Python. scramjit compiles the world here, in this tab, and the agent picks every move by simulating the world's own code. In most worlds more thinking wins more, with no training; the rest need the trained table. Edit the rules and the agent adapts as soon as they recompile.
